A comment above the condition says why, in the file's style: a hook may exit without reading its input; above the pipe buffer the write then fails every time, below it only when the child exits first; the child's status is still its decision. `spawnSync` reports a kill on timeout as `ETIMEDOUT` ahead of a pipe error, so the Copilot timeout branch is unchanged. No new export, no new option, no warning line (a hook that ignores its input is legitimate, so a warning would be noise on every large payload). |
