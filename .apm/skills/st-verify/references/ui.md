# UI axis

The rendered surface, machine-checkable half: which states exist, whether the
design system is actually used, whether a regression would be caught, and the
accessibility criteria a scanner can decide. Judgment covers what it cannot.

Not applicable when the repo has no rendered surface — no component root, no
markup or template files. Every row then records `not-applicable` citing that
absence, per the run contract in `SKILL.md`.

## Runnable checks

Each row: what it establishes · how to run it from detection facts · threshold.

- **`ui-state-render`** — every state a component declares is reachable in render.
  How: enumerate components under the detected component root; for each, list
  declared states (variant props, fixtures, stories) and match them to render
  branches. Threshold: 0 declared states with no branch.
- **`ui-token-usage`** — color, spacing, and type values come from the design
  system rather than literals. How: read the token source named by the
  design-system inventory; count literal values in component files that have a
  token equivalent. Threshold: 0 such literals; an exception carries an inline
  reason on the line.
- **`ui-visual-baseline`** — a visual regression would be caught. How: detect the
  visual-regression harness (baseline directory, snapshot config); confirm
  committed baselines for each top-level surface, and that baselines are not
  regenerated by the same run that changes them. Threshold: baseline present per
  surface; no harness detected is `skipped` with the probe recorded.
- **`ui-contrast`** — text and interface boundaries meet the AA ratios. How: run
  the repo's accessibility scanner over rendered surfaces when one is detected;
  otherwise compute ratios from the foreground/background pairs in the token
  source. Threshold: 4.5:1 body text, 3:1 large text and component boundaries,
  0 violations.
- **`ui-focus-visible`** — every operable element keeps a visible focus ring.
  How: scan the style layer for focus-suppressing declarations and pair each
  with a replacement indicator rule; confirm the system defines a focus style.
  Threshold: 0 suppressions without a paired indicator.
- **`ui-accessible-name`** — every control and image resolves to a name. How:
  scan markup and templates for interactive elements and images; a control with
  no text child, associated label, or naming attribute fails. Threshold: 0
  unnamed controls; 0 images lacking alt text or an explicit decorative marker.
- **`ui-target-size`** — pointer targets clear the minimum. How: read the size
  tokens and utility classes applied to interactive elements. Threshold: 24x24
  CSS px, or documented spacing to neighbours; inline and essential exceptions
  listed with their reason.

## Judgment checks

- **`ui-hierarchy`** — one primary action per surface reads as dominant, and
  secondary actions do not compete with it.
- **`ui-density`** — spacing follows the system scale; ad-hoc values appear only
  where the scale genuinely has no step.
- **`ui-motion`** — motion carries meaning (state change, spatial continuity)
  and honours the reduced-motion preference.
- **`ui-fallback-quality`** — empty, error, and loading surfaces look designed
  rather than unstyled, and match the system's voice.
