**1 — `Critical` — Broken object-level authorization on export retrieval**
`src/api/exports.ts:34`
OWASP `A01:2021 Broken Access Control` / API Top 10 `API1:2023 BOLA`

The handler resolves the export record directly from `req.params.id` and streams it, having verified only that a session exists. Session presence establishes *who is calling*, not *what that caller may read* — no predicate ties the authenticated principal to the resolved record. Any authenticated caller can enumerate `id` and retrieve any tenant's export.

Fix shape for the fixer: the ownership predicate belongs in the record lookup itself, not as a post-fetch comparison — scope the query by the session principal so a non-owned `id` returns not-found rather than forbidden, and the enumeration oracle closes with the access hole.
