## Findings

**`Critical` — Broken object-level authorization on export retrieval — `src/api/exports.ts:34`**
The handler resolves the export record from `req.params.id` and streams it after verifying only that a session exists. Nothing ties the authenticated caller to the resolved record, so any session holder can enumerate `id` values and read other tenants' exports. OWASP `A01:2021 Broken Access Control` / API Security `API1:2023 Broken Object Level Authorization`.
Fix shape: after resolution and before streaming, assert the record's owner (or tenant) matches the session principal; return 404 rather than 403 so the check does not confirm existence.

**`Warning` — Export route registered with no rate limit — `src/api/exports.ts:12`**
The route carries no rate-limiting middleware. On an endpoint that streams stored artifacts this compounds the finding above: it makes id enumeration cheap and leaves the stream open as a resource-consumption vector even once authorization is fixed. OWASP `A04:2021 Insecure Design` / API Security `API4:2023 Unrestricted Resource Consumption`.
