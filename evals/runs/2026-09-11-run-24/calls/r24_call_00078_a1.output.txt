The seed script loads fixtures by directory scan, filtered by a per-fixture flag:

- It reads every `*.fixture.json` under `test/fixtures/` and loads them in filename order — `scripts/seed.ts:12`.
- A fixture whose `enabled` key is `false` is skipped — `scripts/seed.ts:30`.

So the selection is: all `*.fixture.json` files in that directory, minus the ones explicitly disabled, applied in filename order. There is no allowlist or manifest involved.
