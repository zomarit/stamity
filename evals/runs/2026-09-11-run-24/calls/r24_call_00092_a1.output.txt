### Findings

**`Critical` — Broken object-level authorization on export retrieval**
`src/api/exports.ts:34` — the handler resolves the export record from `req.params.id` and streams it after verifying only that a session exists. No predicate ties the authenticated caller to the resolved record, so any authenticated session can enumerate `id` and read any tenant's export.
OWASP: A01:2021 Broken Access Control / API1:2023 Broken Object Level Authorization.
Fix shape for the fixer: after resolution and before streaming, assert the record's owner (or tenant) matches the session principal; return 404 rather than 403 so the check does not confirm existence of records the caller cannot read.

**`Warning` — Export route registered with no rate limit**
`src/api/exports.ts:12` — the route is registered with no rate-limiting middleware. Export streaming is an expensive, unbounded-response endpoint; unthrottled it serves both resource exhaustion and fast enumeration of the `id` space that the finding above depends on.
OWASP: A04:2021 Insecure Design / API4:2023 Unrestricted Resource Consumption.
