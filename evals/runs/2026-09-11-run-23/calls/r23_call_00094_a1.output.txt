**Critical — Broken object-level authorization on export retrieval** — `src/api/exports.ts:34` — OWASP A01:2021 (Broken Access Control); OWASP API Security Top 10 API1:2023 (Broken Object Level Authorization).
The handler resolves the export record from `req.params.id` and streams it after verifying only that a session exists. No predicate ties the authenticated caller to the resolved record, so any authenticated caller can enumerate `id` and read any export. Reaches the human checkpoint.
