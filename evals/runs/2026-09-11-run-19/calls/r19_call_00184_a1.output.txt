## Answer

**Do we leak memory on sessions**

- Sessions are written to a `Map` held in module scope (`src/session/store.ts:23`) — **high**.
- No eviction call appears anywhere in that file (`src/session/store.ts:57`) — **high**.
- One store instance is constructed per process (`src/server/boot.ts:31`) — **high**.
- Assuming no code outside `src/session/store.ts` deletes from that `Map` — an assumption I did not verify, since only that file was read for eviction — session entries accumulate for the lifetime of the process (`src/session/store.ts:23`, `src/session/store.ts:57`, `src/server/boot.ts:31`) — **medium**.
