```text
Flag declaration:
  --json   boolean, default false, no value argument, no short alias.

stdout payload — exactly one JSON object, no wrapping text, no trailing output:
  {
    "workspace":    string,
    "branch":       string,
    "managedFiles": integer,
    "driftedFiles": integer,
    "lastSync":     string
  }
  All five keys always present. No key is nullable. No additional keys.

Exit codes:
  0  success, no drift finding
  1  drift finding

stderr:
  empty on success.
```

**`testCriteria`**

- `stamity status --json` writes a single `JSON.parse`-able object to stdout and nothing else.
- The parsed object's key set is exactly `workspace`, `branch`, `managedFiles`, `driftedFiles`, `lastSync`.
- `workspace`, `branch`, `lastSync` are strings; `managedFiles` and `driftedFiles` are integers.
- Exit code is 0 when there is no drift finding, 1 when there is one.
- stderr is empty on a successful run.
- Without `--json` the existing human-readable output is unchanged (default false).
- `--json` consumes no following argument: `stamity status --json` parses with no positional left over.

**`edgeCases`**

- *Drift present.* The full JSON object still goes to stdout and stderr stays empty; the finding is carried by exit code 1 alone, not by a stderr message.
- *Zero managed files.* `managedFiles` is the integer `0` — the key is emitted, not omitted, and not `null`.
