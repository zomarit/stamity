**1 — `Critical` — Broken object-level authorization on export retrieval**
`src/api/exports.ts:34`
The handler resolves the export record from `req.params.id` and streams it after verifying only that a session exists. Nothing ties the authenticated caller to the resolved record, so any session holder can enumerate `id` values and read other tenants' exports. Authentication is present; authorization is absent.
OWASP: A01:2021 Broken Access Control · API1:2023 Broken Object Level Authorization
Fix shape for the fixer: the ownership predicate belongs in the record lookup itself, not in a branch after it — scope the query by the session principal so a non-owned `id` returns not-found rather than a record the handler must then decide about.

**2 — `Warning` — Export route registered with no rate limit**
`src/api/exports.ts:12`
The route is registered without a rate limit. Export streaming is an expensive, ID-addressable endpoint; unthrottled it also makes the enumeration implied by finding 1 cheap to run at scale.
