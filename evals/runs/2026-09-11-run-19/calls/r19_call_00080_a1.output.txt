The seed script loads fixtures by directory scan, filtered on an opt-out flag:

- It reads every `*.fixture.json` under `test/fixtures/` and loads them in filename order — `scripts/seed.ts:12`. There is no explicit manifest or allowlist; membership in the directory plus the filename glob is what selects a fixture.
- A fixture whose `enabled` key is false is skipped — `scripts/seed.ts:30`. So the only per-fixture control is that flag; absent it, a matching file is loaded.

Ordering is filename order, which means load sequence is controlled by naming convention rather than by anything declared in the fixtures themselves.
