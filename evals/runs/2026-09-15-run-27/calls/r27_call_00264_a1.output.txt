## One gap to decide before I write

`REQ-cli-140` pins stderr only for the success path — "nothing is printed to stderr on success." It is silent on whether the drift path (exit `1`) may write to stderr. I have written the unit assuming stderr stays empty there too, since `--json` output is meant to be machine-consumed and a drift finding is a normal result rather than an error. If the spec intends a drift warning on stderr, say so and I will change the edge case and testCriteria before the write rather than after.
