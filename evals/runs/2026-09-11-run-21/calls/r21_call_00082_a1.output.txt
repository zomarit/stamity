The seed script selects fixtures in two steps:

- It reads every `*.fixture.json` under `test/fixtures/` and loads them in filename order (`scripts/seed.ts:12`).
- It skips any fixture whose `enabled` key is `false` (`scripts/seed.ts:30`).

So the effective set is: all `*.fixture.json` files in that directory, minus the ones explicitly disabled, applied in filename order.
